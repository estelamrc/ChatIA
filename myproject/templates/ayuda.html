Ayuda

Guía rápida de uso de ChatIA.

¿Qué es ChatIA?

ChatIA es una aplicación web desarrollada con Django que permite mantener conversaciones con un modelo de inteligencia artificial mediante una API externa de NVIDIA Build.

Usuarios

Puedes registrarte, iniciar sesión y cerrar sesión. Cada usuario tiene sus propias conversaciones, mensajes y configuración personal.

Conversaciones

Puedes crear nuevas conversaciones, abrir conversaciones anteriores, editar su nombre, marcarlas como favoritas o eliminarlas.

Favoritos

Las conversaciones favoritas aparecen destacadas con una estrella y se muestran primero en la barra lateral izquierda.

Títulos automáticos

Cuando creas una conversación nueva, ChatIA puede generar un nombre automáticamente a partir del primer mensaje. Si editas el nombre manualmente, ya no se cambia automáticamente.

Memoria de conversación

ChatIA mantiene el contexto de cada conversación. Esto permite que la IA recuerde mensajes anteriores dentro del mismo chat.

Configuración

Desde la configuración puedes cambiar tu alias, la temperatura del modelo y el tamaño de letra de la interfaz.

Envío de mensajes

Puedes enviar mensajes pulsando el botón Enviar o usando la tecla Enter. Si quieres escribir varias líneas, puedes usar Shift + Enter.

Conversaciones públicas

Puedes compartir conversaciones mediante un enlace público usando el icono 🔗. El enlace se copia automáticamente al portapapeles y permite visualizar la conversación en modo solo lectura.

Recurso JSON

Cada conversación tiene un recurso JSON propio. Puedes visualizarlo con el botón Ver JSON o descargarlo usando el botón de descarga.

HTMX

El chat usa HTMX para enviar mensajes y actualizar partes de la página sin recargarla completa, como la conversación activa y la barra lateral.

ChatIA escribiendo

Mientras se genera una respuesta, aparece un indicador visual para mostrar que ChatIA está procesando el mensaje.

Diseño

La interfaz usa Bootstrap, CSS propio, favicon personalizado y una estructura responsive para adaptarse a distintos tamaños de pantalla.

Seguridad

Las páginas privadas requieren iniciar sesión. Django gestiona la autenticación mediante sesiones y protege los formularios con CSRF.
